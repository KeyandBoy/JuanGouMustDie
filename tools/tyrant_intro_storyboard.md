# 暴君登场 · 分镜 CG 内容包（脚本来源）

> **状态（2026-11-04）**：这份文稿是**分镜脚本的文本来源**，最终实现没有用 AIMangaStudio（浏览器直连 Google 被墙 + 用户提供的是 OAuth 令牌而非 API key）。
> 实际管线是：`tools/manifests/tyrant_intro_panels.json`（12 格 prompt）→ `tools/gen_panels.py`（imagefree）→ `tools/compose_manga.py`（排成 4 页漫画）。
> 本文件保留世界观/角色/逐格描述，改台词或调整镜头时先改这里，再同步到 manifest。

> 用途：在 `aimangastudio`（本地 `http://127.0.0.1:5173`）里「世界观设置 + 场景脚本」直接粘贴本文件的内容，生成暴君登场过场 CG。
> 画幅：**横版 16:9**（游戏内 2×2 四格，每格一张）。
> 风格基准：现有 `art/cutscene/tyrant_p1~p4.png`（黑白漫画 + 单一红色点缀、粗墨线、网点）。

## 一、世界观设置（Worldview）

```
作品名：《卷狗必须死》（JuanGou Must Die）——校园恐怖动作游戏。

世界观：一所被"内卷"吞噬的高中。学生被排名、刷题、竞赛异化成"卷狗"；
真正的怪物是被卷死的历代年级第一——他们从未毕业，被埋在校舍地基里，
靠吞噬后来者的分数、睡眠与血肉维持形态。学校把他们的尸体砌进了走廊尽头。

视觉基调：黑白漫画。粗墨线、强对比、密集网点；唯一彩色是"红"——
血、眼睛、警示字、试卷上的红叉。恐惧来自"熟悉之物被扭曲"：教室、走廊、试卷、课桌。

绝对铁律（违反即废稿）：
- 怪物只能是两条腿，脚必须穿厚黑皮靴、裤脚塞进靴筒；禁止三条腿、断脚、漂浮肢体。
- 暴力可以血腥，但结构必须清晰：先看清轮廓，再看到血。

这一段过场的任务：暴君在走廊尽头苏醒，玩家第一次看见它，然后开始逃命。
```

## 二、角色设定（如需建角色表就用这两段）

### 主角 · 「我」（可省略，只在脚本里描述）

```
高二男生，十七岁。乱翘的黑色短发，眼下浓重黑眼圈，深蓝色校服外套敞着，
里面是被汗浸透的白衬衫，校服袖口有干涸血迹，手里攥着一张被血浸红的试卷。
表情是长期熬夜后的麻木与惊恐。黑白漫画人物，粗描线，网点阴影。
```

### 暴君 · TYRANT（核心，必须严格一致）

```
一具被缝合起来的年级第一尸体，巨大、畸形、缓慢。身高约三米。
苍白尸体皮肤，布满深色粗缝合线与暗红血痂；胸口正中与右臂被撕裂，露出鲜红肌肉纤维，血顺着往下滴。
三只发光的红眼：正常位置两只，额头正中有第三只，全部只有红光没有瞳孔。
左肩上嵌着半张骷髅脸（只有上半个头骨和牙齿，朝后）。
背脊与前臂长出一排排骨刺，像折断的粉笔。
右臂异常巨大，肌肉暴起，指节拖着血；左臂相对干瘦。
下身穿破烂的深色校服长裤，裤脚塞进厚黑皮靴，靴面沾满血。
站姿前倾，像被自己的重量拽着走。
黑白漫画风格，粗墨线，密集网点阴影，红色只用于三只眼睛与血。
```

## 三、逐页场景脚本（每页粘贴到「场景脚本」框，选「黑白」）

> 每页 2~3 格，镜头按 电影分镜 写。对白尽量少（生成时中文对白容易糊），主要靠画面。

### 第 1 页 ·「走廊尽头」

```
第1格：深夜教学楼走廊的广角镜头。两侧是整齐到诡异的教室门，顶灯只亮一盏，在远处明灭。地面反光，墙上有用红色粉笔写的巨大数字"1"。空气里有灰尘悬浮。压迫、空旷。

第2格：主角的背影，站在走廊入口，手里攥着一张被血浸透的试卷，试卷边缘滴下一滴血。他僵在原地不敢动。中景，略微仰视。

第3格：走廊尽头的黑暗里，出现一个不成比例的巨大黑色轮廓，只看得清两点红光和一只更高的第三只红眼。轮廓比门框还宽。极远景，大面积留黑。

画风：黑白漫画，粗墨线，密集网点，红色只出现在红眼和血滴上。
无对白。
```

### 第 2 页 ·「它看见你了」

```
第1格：暴君的中景。它低着头，三只红眼同时亮起，额头那只先睁开。肩上嵌着半张骷髅脸，骨刺从背脊刺出。胸口撕裂处露出鲜红肌肉，血顺着往下滴到黑皮靴上。

第2格：主角的脸部特写，瞳孔骤缩，汗顺着下颌滴下，嘴唇发抖。背景全黑，只有一侧脸被走廊冷光照亮。

第3格：暴君迈出第一步，巨大的黑皮靴踩进画面，地板龟裂。仰视，低机位贴地，靴子几乎压到镜头上。

画风：黑白漫画，粗墨线，强对比，密集网点，红色只用于红眼与血。
无对白。
```

### 第 3 页 ·「追」

```
第1格：走廊纵深追猎。暴君从深处冲出，身体前倾，巨大右臂甩在身后，骨刺划破墙面留下白色划痕。动态模糊，斜切格子，地面线条向灭点汇聚。

第2格：主角翻过一张课桌，试卷与纸页在空中散开，纸片被红色血滴打湿。侧身中景，速度线。

第3格：暴君的手掌撞穿教室门，木屑与玻璃飞出，门板上留下血手印。特写，冲击构图，格子被掌印撑破。

画风：黑白漫画，粗墨线，速度线，密集网点，红色只用于红眼与血。
无对白。
```

### 第 4 页 ·「别回头」

```
第1格：主角冲进楼梯间，回头一瞬。他的眼睛里反射出走廊深处的三点红光。近景，浅景深。

第2格：暴君站在走廊中央，头顶顶灯炸裂，玻璃碎屑落下；它张开撕裂的下颌，血从牙缝拉丝。低角度仰拍，格子顶部被它的头顶撑破。

第3格：全黑画面，只有巨大的白色手写字"快跑"。字边缘有血溅。极简，冲击。

画风：黑白漫画，粗墨线，密集网点，红色只用于红眼与血。
无对白。
```

## 四、生成后处理与接入

1. 每页导出 PNG → 存为 `art/cutscene/tyrant_p1.png` … `tyrant_p4.png`（覆盖旧图，先备份）。
2. `scripts/main.gd` 第 ~1276 行四格版式按 **16:9** 计算（`img_h` 用 `* 9.0/16.0`，`img_w` 上限用 `* 16.0/9.0`）。
3. `--headless --import` → 四套测试 → `tests/screenshot.tscn` → 目视 `tests/shot_tyrant_comic.png`。
4. 字幕文案（`texts` 数组）按最终画面再校一遍。
